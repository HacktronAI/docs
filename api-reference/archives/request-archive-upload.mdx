---
title: "Request archive upload"
openapi: "POST /archives/uploads"
description: "Get a URL to upload a code archive to, for code that isn't in a connected repository."
---

Returns a signed URL to upload a `.zip`, `.7z` or `.tar.gz` archive of source code to.

<Info>**Scope required**: `write`. **Role**: member or above.</Info>

1. Call this endpoint with the archive's `file_name`.
2. `PUT` the file to `upload_url`, with the `Content-Type` header set to the returned `content_type`.
3. Pentest it by adding `{ "source": "upload", "archive_id": "<id>" }` to `repos` in [Create pentest draft](/api-reference/pentests/create-pentest).

To pentest only part of the archive, set `include_paths` or `exclude_paths` on that repo instead of uploading a smaller archive.

<Note>
  Some self-hosted installs don't support uploads through the API and return
  `400`. Upload the archive in the Hacktron web app instead.
</Note>
