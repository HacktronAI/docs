---
title: "Update PR review settings"
openapi: "PATCH /pr-review-settings"
description: "Change how PR reviews behave across your organization."
---

Updates your organization's PR review settings and returns the full settings object. Only fields in the request change. Send `null` to disable `fail_on_severity` or clear a filter.

<Info>**Scope required**: `write`. **Role**: organization admin.</Info>

Each filter replaces the saved list. To add a branch without removing existing entries, first read [Get PR review settings](/api-reference/repos/get-pr-review-settings), then send the full list with your addition.

Branch and author filters take glob patterns (`*`, `**`, `?`, `{a,b}`) and are case-insensitive. Each filter holds up to 50 entries.
