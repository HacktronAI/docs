---

Hacktron bills each product separately. Code Review runs on seats, with a 14-day free trial. Whitebox Scans and Automations each run on their own credits, which are organization-wide and kept separate from each other.

## How billing works

| Product | Billed by | Charged when |
| --- | --- | --- |
| [Code Review](/code-review/billing) | Seats | Monthly, for seats active during the period |
| [Whitebox Scans](/white-box-pentest/billing) | Scan credits | Starting the scan, after estimation of credits completes. |
| [Automations](/platform/automations/credits) | Automation credits | When a remediation run completes |

Organization owners manage billing. Other members cannot see the Billing page.

## Code Review

Code Review is billed by seat. Each developer with Code Review enabled counts as one seat, charged monthly for the seats active during that billing period. Every organization starts with a 14-day free trial. Learn more about it [here](/platform/billing/code-review). 

## Whitebox Scans

Whitebox Scans run on organization-wide scan credits. Estimate a scan's cost before you start it, and credits are deducted when it completes. Learn more about them [here](/white-box-pentest/billing).

## Automation Credits

Automation credits are organization-wide. They are separate from Code Review seats and your Whitebox Scan credits. Every paid organization starts with \$50 in Automation Credits. 

Learn more about them [here](/platform/automations/credits).

## Payment methods and Invoices

Organization owners add and manage payment methods from **Billing**, where you can also view invoices and recent billing activity.
